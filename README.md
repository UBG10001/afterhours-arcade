# Afterhours Arcade

A responsive browser arcade with 248 real games, including Snow Rider 3D and Slope. Features instant search, 12 category filters, alphabetical sorting, favorites and recent history stored on the device, random game selection, and a fullscreen player.

## Play

The site is published through GitHub Pages. The `Publish arcade` workflow deploys the `dist` directory whenever `main` changes.

## About:blank launcher

Direct visits attempt to open a new `about:blank` tab containing a full-window iframe of the exact arcade URL, including its query and selected-game hash. The original tab attempts to close only after the framed arcade confirms that its catalog is ready. Embedded visits never launch another tab.

Browsers may block automatic pop-ups or refuse to close a tab they did not open. In those cases the launcher offers an explicit Open arcade button, a Play in this tab fallback, and a manual-close notice. It uses standard browser APIs and does not change browser settings, disable extensions, or guarantee filter bypass.

## Game hosting

Eight games are included directly with their source and license notices: 2048, Hextris Lite, Astray, Radius Raid, JavaScript Tetris, Snake, Match-3, and Bubble Shooter. These run from this site's own origin. Upstream revisions, authors, modifications, and license information are preserved in each game's `attribution.json` and `ARCADE-NOTICES.md`.

The other 240 games use public publisher embeds from GameMonetize, GameDistribution, and Y8. Those games require access to their publisher servers and may include ads or consent prompts. Snow Rider uses the required current-page referrer parameter. No proprietary publisher game files are included in this repository.

The arcade does not disable school extensions or guarantee access through network filters. GitHub Pages and any external game domain may still be blocked.

## Local preview

Run `node server.mjs` and open `http://127.0.0.1:4173`. No dependency installation or build is required. `node verify.mjs` checks the catalog, local games, referenced assets, and app syntax.

## Updating games

Edit `dist/catalog.json`. Entries contain a unique `id`, `title`, `category`, `instructions`, `description`, `embed`, `thumbnail`, `provider`, and `sourceUrl`. A self-hosted entry also has `local: true` and relative game/thumbnail URLs. Keep the publisher's branding and the game's license notices. Catalog credits are generated by `node generate-credits.mjs`.

## Validation

All 240 publisher embed endpoints and all 240 original thumbnail endpoints returned success when checked on September 18, 2026 UTC. Sample player flows and all eight local game initial loads were checked. This does not imply a full gameplay walkthrough of every publisher game. Availability can change independently of this site.
